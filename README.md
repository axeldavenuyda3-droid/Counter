# Tap Tally (React Native + Expo)

## What the app does
Tap Tally is a simple counter app. You can add 1 (+), subtract 1 (−),
or reset the number to 0. It also supports dark mode, which follows
your phone's theme.

## Built with
- React Native (Expo)
- Core components: View, Text, Pressable
- useState, props, StyleSheet.create(), Flexbox, useColorScheme

## How to run
1. npx create-expo-app MyApp
2. Replace the App.js file with the one in this repository
3. cd MyApp
4. npx expo start
5. Open the app on your phone with Expo Go, or use an emulator
